# MEP Website

*MathScript Enhancement Proposal*s (MEPs) are the current and proposed specifications
of the MathScript language and its ecosystem.

This repository hosts both the website to display them, and the MEPs themselves.
It is made using VuePress, allowing for a simple codebase, the use of Markdown,
the ease for people to make drafts and edit MEPs, and the version control integration.

## Writing a MEP

You may read the Meta-MEP ["Writing"](https://mathscript-lang.github.io/MEP/Writing.md).
